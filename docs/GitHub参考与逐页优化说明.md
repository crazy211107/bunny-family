# 兔兔小窝 · 参考分析与逐页改版说明

更新：2026-10-28。交付对象为现有微信原生小程序，已完成的适配继续保留。白兔是豆米，黄兔是豆糕。

## 本轮方向

将九个页面统一成一本可用的奶油手账：照片负责叙事，票根负责摘要，分组列表负责操作。压缩重复介绍、卡片留白与无意义装饰，同时保留主要操作触区。正文、时间与操作文字加深；粉、绿、黄用来区分操作、完成与回顾。

保留故事目录与兔耳快捷球，没有传统底部 tabBar。工坊采用“仅目录”模式，编辑工具不受悬浮球遮挡。真实照片、轻纸纹、胶带和不对称排版保持原定的可爱感；电影感来自取景、胶片与放映。

## GitHub 功能参考的具体分析

### EinVault：提醒应当可执行，交接应当能带走

核对了 [项目功能说明](https://github.com/davefatkin/EinVault) 和 [循环提醒服务源码](https://github.com/davefatkin/EinVault/blob/main/src/lib/server/reminders.ts)。源码将完成/跳过区分，下一次提醒按系列锚点计算，并通过事务避免重复派生；README 的 caretaker sheet 将照顾说明、日程与联系人组织到可打印的一页。

本项目采用适合本机小程序的方案：日期序号确定周期、`计划 id:日期` 确定完成记录，不会因迟打卡把计划顺延；收起计划保留历史日志。将未来三天待办、双兔说明、补给与联系方式汇成交接文字和精简图片。没有照搬服务器事务或伪造云协作。

### Memos：记录之后，还应能找回来

核对了 [项目说明](https://github.com/usememos/memos) 与 [筛选组合实现](https://github.com/usememos/memos/blob/main/web/src/hooks/useMemoFilters.ts)。内容、标签、置顶和日期具有独立筛选维度，便于长期回看。

落地为日记的置顶优先、标签计数与标签浏览，与原来的心情/兔兔/日期筛选组合。补上自动草稿恢复、编辑原 id 保留与提交后不重写草稿，使写作中断也可继续。

### Immich：主题册与时间回忆解决不同的寻找方式

核对了 [项目功能说明](https://github.com/immich-app/immich) 与 [回忆生成服务](https://github.com/immich-app/immich/blob/main/server/src/services/memory.service.ts)。回忆按日期/年份组织，资产集合去重；主题相册提供另一种组织方式。

本项目原有月归档和往年今日，本轮补的是命名主题册、封面、批量加入/移出，以及照片回收后的有效封面回退。相册只保存照片 id 引用，不复制文件。没有复制 Immich 的 AGPL 源码、素材或引入其服务端。

## 一致性、响应式与可访问性

- 统一基础层、组件层、响应式层；标题/说明/数值/动作分工稳定，重要信息采用更深的可可色。
- 紧凑通过缩短冗余介绍、卡片内边距和区块间距实现，主要操作仍保留至少 88rpx 触区；筛选通常为 80rpx。
- 340–350px 窄屏允许标题与表单换行、照顾格改为两列、部分装饰隐藏；宽屏限制内容列；输入和列表使用 `min-width:0`。
- 抽屉避开系统胶囊；内容区弹性滚动，底部考虑安全区；画布不被快捷球挡住。
- 原生 button 保留系统语义；自定义按钮使用 `aria-role` 与明确的 `aria-label`；完成状态有勾选和文字，日程只读状态有说明。
- 动效限于透明度和 transform，响应减少动效偏好；数据加载/导出有实际进度，空态提供下一步。
- 这些属于代码层面的可访问性改进，尚未完成 iOS VoiceOver、Android TalkBack、系统放大字体和各真机横竖屏验收。

## 交付边界与复现

变更集中在 `miniprogram/`，浏览器原型不与本轮原生功能同步。旧本机数据按增量字段兼容，新增集合默认空，不伪造照顾历史或库存。

验证分层与具体命令见 `本轮验收记录.md`。目前已完成本地官方编译、页面/组件/事件扫描、绘图管线检查与 13 组行为检查；仅手账墙取得开发者工具窗口截图，其余页面未完成新版截图验收。不能据此宣称在通用相册、云协作能力上超过成熟开源项目；优势在于把照片叙事、双兔照顾、补给和家庭交接放进同一套小程序流程。
