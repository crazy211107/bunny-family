# 兔兔小窝 · 微信小程序设计编码交接

## 交付入口与阅读顺序

1. 运行浏览器交互原型，体验页面、菜单、抽屉和创作闭环。
2. 阅读 `专家增强提示词与功能闭环.md`，这是本轮专家审查后形成的增强规格。
3. 阅读 `兔兔家庭小程序-优化提示词.md`，了解完整产品范围与微信分阶段接入说明。
4. 对照本交接稿和源码进行微信小程序设计编码，不能把网页 CSS / DOM 直接当作 WXML 实现。

## 用户最终确认的视觉与身份

- **白色兔兔：豆米；黄色兔兔：豆糕。** 内部 `qiu` 对应豆米、`dou` 对应豆糕，是为保留早期原型记录而保留的稳定 ID；界面不显示这些内部名称。
- 严格遵循原稿的**奶油系可爱手账**，电影感来自回忆放映、胶片边框、真实兔兔画面和故事翻页。
- 禁止暗色大片海报、商务蓝、常规侧栏后台、默认底部 tabBar 和传统底部导航条。
- 右上角「翻开目录」打开故事书；底部只有一个独立兔耳果冻母按钮，向上展开拍照片 / 录视频 / 记一笔 / 召唤兔兔四项扇形动作。
- 首页大标题「我们家 ♡」，正文意境「小日子，慢慢放映。」；不要因增加功能而把首页改成密集功能网格。

## 需要保持一致的交互细节

### 照顾与日历

打卡键为 `petId:YYYY-MM-DD`，值只允许喂草 / 换水 / 铲屎 / 陪玩四项时间。首页、今日场记、宠物档案和月历读取同一份资料。同一天重复点击是撤销，不新增重复记录。历史日期只读，未来日期不能打卡；统计不能把空白历史当作已完成。

### 日记

编辑保留原 ID 与创建时间，另记更新时间。日记关联稳定 petId 与 photoId；关联照片进入回收站时显示安全提示，编辑器提供取消隐藏关联的入口。删除进回收信箱，可恢复。今日场记只显示当天的有效日记，全部历史去「小日子信笺」搜索查看。

### 相册

照片搜索覆盖标题、分类与关联兔兔名字。多选只作用于当前可见集合；筛选变化不能误操作隐藏项。照片软删保留 Blob，先实现恢复，避免未经确认的物理清除。放映依据 ID 定位，当前项不存在时安全切换，整个集合为空时显示空状态。

多图上传逐张处理，最多一次 12 张，显示真实处理进度与逐张失败结果；取消选择不报错。上传不推断照片中的兔兔身份，用户可在相册资料中指定。

### 照片工作台

- 四格模板为四个独立槽位，各自选照片；双图曝光可选择副照片，不选择时为同图叠影。
- 撤销历史最多 30 步；一次拖动、一次滑杆操作或一条笔画只提交一步。撤销后新编辑清空 redo 分支。
- 草稿保存主照片 ID 和序列化设置，不能保存对象 URL、Canvas 或 Image 对象。恢复时文件缺失要提示，不静默换成另一张照片。
- 画笔包括马克笔 / 荧光笔 / 虚线笔 / 马赛克，马赛克取样不可变的底层照片；最多 200 条笔画。
- 副素材仍在解码或读取失败时阻止导出，防止生成与预览不同的作品。
- 文字、模板、调色、贴纸与笔画复用同一绘图函数；选中框只在预览出现。

## 数据模型与迁移

网页原型仍读取 `bunny-cinema-v1` 本地键，内部新增 schemaVersion=2。旧宠物、打卡、家人、照片、日记和视频会迁移合并，不清空用户资料。真实名字迁移只执行一次，之后用户自定义昵称继续保留。

新增字段：

- photo：`petIds[] / tag / date / liked / trashedAt`。
- note：`date / mood / petIds[] / photoIds[] / tags[] / createdAt / updatedAt / trashedAt`。
- editorDraft：`id / name / photoId / settings / updatedAt`。
- settings：模板 / 字迹 / 调色 / 贴纸 / photoSlots / secondaryId / strokes。

小型资料在 localStorage，媒体 Blob 在 IndexedDB。微信端请替换为适配层；本地持久化成功不等于云端同步成功。正式云开发需家庭成员权限校验、按家庭隔离、幂等写入、并发更新与文件生命周期。

## 已实现与后续能力边界

本地原型的照顾日历、日记、相册整理、照片编辑和 PNG 生成均有真实状态与数据处理。微信登录、跨设备同步、订阅消息、人脸 / 语音识别、双指组合手势、MP4 裁切转场合成、授权 BGM 尚未接入。

视频页保存的是原片段和编辑参数；滤镜及字幕只是预览，不能把草稿称为已导出的成片。微信基础库、字体加载、SVG / CSS 支持、订阅消息约束和媒体服务能力应在正式迁移时查当时的官方文档并做真机验证。

## 验证与接收

已完成生产构建、核心状态测试和服务端源码渲染检查。检查覆盖旧数据迁移、真实姓名、双兔隔离、连续打卡、撤销分支与上限、空相册 / 全部软删、缺失放映 ID 和隐藏关联照片。

本机 HTTP 页面返回 200，用户已确认可以正常打开。内置浏览器自动访问曾遭安全策略阻止，因此没有把源码测试当作手机截图验收或浏览器全流程点击验收，也没有宣称微信真机验证通过。

后续微信验收至少覆盖 375 / 390 / 768px 页面、抽屉与扇形触控、文件选择取消、每日日期边界、空相册恢复、30 步撤销 / 重做、拼图换图加载、草稿重开和 2× 图片导出。功能验收与视觉验收均通过后再接云能力。
