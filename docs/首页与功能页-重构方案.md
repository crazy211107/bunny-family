# 兔兔小窝：首页与照顾工作台

> 已撤下的 Web 试验，仅保留历史。用户已明确纠正为「微信小程序 + 原可爱手账风格」，本方案不能用于继续开发。当前真源为 `兔兔小窝-主提示词.md` 与 `原生可爱风格校正.md`。

2026-10-29；本轮是现有 Web 工程的增量重构，微信原生的九页业务和已修复的 AI 样式继续保留。

## 信息架构与路由

```text
#/home 首页
  ├─ 主 CTA / 移动导航 → #/care 照顾工作台
  ├─ 相册 → #/album
  ├─ 手账 → #/diary
  └─ 豆伴 → #/ai
#/care
  ├─ 返回首页 → #/home
  ├─ 兔兔档案 → #/pets
  └─ 豆伴 → #/ai → 会话列表 → 来源工作台
```

所有核心入口都是可操作的链接或按钮。`src/App.jsx` 维护路由与家庭状态，支持 hash 直接访问与地址变化；AI 保存来源路由和页面滚动位置。返回不承担新建、折叠或打开抽屉的职责。

## 首页 section 与布局

| 顺序 | 实装组件 / 布局 | 证据、交互与取舍 |
| --- | --- | --- |
| 1 Header | ProductHeader，紧凑横向路由，移动展开导航 | “进入工作台”在桌面/移动都可直接操作；品牌回首页 |
| 2 Hero | 左侧价值与 CTA；右侧真实照片 + ProductProof | 用户提供的豆米/豆糕原始照片；实时读取与工作台相同的今日记录，每只四项，未知完成数不会被填满；不是假截图或装饰光球 |
| 3 摩擦说明 | 三列叙事，移动两列对比 | 零散查找 → 按兔兔查看/明确时间/可撤销；没有虚构节省时长 |
| 4 结果模块 | FeatureModule 两段左右交替，移动自然堆叠 | “照顾好今天”和“留下回忆”，分别进入工作台、手账、相册与 AI；没有将所有内容塞成同款 bento |
| 5 工作流 | 四步有序列表，移动 2×2 | 主动记录 → 查看修改 → 按需整理 → 用户决定保存；不编造审核发布功能 |
| 6 信任 | 本机数据/控制边界说明，可展开 | 声明照片来源与独立存储，无虚构客户 logo 或评价 |
| 7 FAQ | 可键盘操作的原生 details | 无订阅套餐的私人项目，因此省略 Pricing；明确 AI 服务商费用与备份边界 |
| 8 Footer | 工作台、资料说明、使用说明 | 均有有效动作；没有虚构法律协议与空链接 |

没有紫/蓝 blob、持续 marquee、粒子或假打字。真实照片底部的静态暗化只保证叠字可读，不作为背景装饰。品牌与空态使用原创兔耳矢量，关键区不是统一 Lucide；操作图标继续复用 Lucide 保持识别度。

手机优先将实时记录卡放在照片之前，避免大照片将产品证明挤出首屏；桌面使用照片与卡片的轻叠层。标题在窄屏收敛到 33–42px，避免中文长行意外变成三行。

## 照顾工作台

统一 PageHeader 包含返回/面包屑、标题、短说明、唯一填色主操作“记录选中”。头部不重复放“进入工作台”主按钮。

- **真实记录**：共用原浏览器的 `petId:YYYY-MM-DD` 照顾键；单项打卡/撤销与旧兔兔档案互通，不新增伪造数据。
- **批量记录**：只处理明确勾选的未记录事项；改变筛选后清除选择，避免隐藏选择被意外提交。
- **筛选**：日期、兔兔、状态和关键词；日期严格校验，禁止未来，历史只读。
- **表格**：13px UI / 10–12px 辅助文字，细边框、明确列头、记录状态和时间；右侧七日真实记录，点击日期回看。
- **CSV**：导出当前筛选下的实际数据，UTF-8 BOM；对用户字段的公式前缀转义，防止直接作为电子表格公式执行。
- **empty**：筛选无结果时给出具体说明；**error**：存储错误保留说明且禁发变更；**disabled**：无选择/历史日期不可记录；**loading**：DataTableState 提供读取骨架，当前同步本机读取不人为加入延迟假装加载。

桌面为表格 + 辅助列；1000px 以下收紧侧列，760px 以下单列并将筛选变为网格。移动表格保留必要列，外容器可横向滚动、可键盘聚焦，避免挤坏单元格；没有在手机上强塞桌面侧栏。首页 CTA、主表格操作、主题/AI 导航均有 focus-visible，尊重 reduced-motion，禁用动画时内容立即稳定呈现。

## 运行、核心代码与验收

```powershell
npm ci
npm run dev
# 首页 http://127.0.0.1:5188/#/home
# 工作台 http://127.0.0.1:5188/#/care
# AI http://127.0.0.1:5188/#/ai
npm run verify:product
npm run verify:chat
npm run build
```

验收：首屏有真实照片与可解释的完成统计；首页进入工作台不依赖返回；功能区信息密度明显高于首页；两页共用 token/Button；记录/撤销/批量/筛选/历史只读/导出可操作；空/错/禁用有反馈；真实 App 的首页→工作台→AI→来源页路径可达；键盘与 reduced-motion 样式存在。

当前证据是 TypeScript/Vite 构建与隔离 React DOM 行为测试。内置浏览器无法访问本机预览，尚无本轮浏览器像素截图、手机真机和完整读屏验收；没有把静态/CSS检查等同这些结果。Web 的新首页/工作台不是微信原生页面，原生仍通过独立本地编译检查。
