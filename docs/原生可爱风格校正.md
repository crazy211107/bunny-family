## 已纠正

1. 撤下 Web 的 LandingHome / CareWorkspace 主入口，浏览器恢复原 `Home.jsx` 手账首页。相关实验文件只作历史保留。
2. 原生首页保持照片放映、胶片、两位小主、手账与故事目录，增加「今天的小小照顾」便签；统计来自当天真实 checkins，点击跳转 `/pages/care/index?tab=daily`。
3. 原生照顾页在原日程、分工、补给基础上添加「照顾打卡」：兔兔/状态筛选、单项盖章与撤销、选择后批量记录、历史只读、复制当前筛选小票。采用拍立得小头像、粉绿便签和印章，不是桌面数据表。
4. AI 面板改回奶油/粉绿/可可文字，入口和页头复用原 `bunny-mark`。保留返回、配置、流式生成、停止/重试、资料范围与历史。
5. 没有改动已有照片、生日、日记、计划或库存；新增打卡直接复用原 `checkins`。保存失败不污染缓存，重复盖章不重置原时间。
6. `redesign.wxss` 拆分保持取消，样式都在现有组件 WXSS 内，不增加热重载路径依赖。

## 使用与验证

微信开发者工具打开项目根目录，`project.config.json` 已指向 `miniprogram/`。编译后：首页 →「今天的小小照顾」→ 照顾打卡。日程、补给、右上故事目录和返回入口保留。

```powershell
npm run verify:miniprogram
npm run verify:native-compile
# 仅本次原生打卡与风格检查
npm run verify:product
```

新增 9 组 wx 隔离检查覆盖：原生入口与真实统计、原有日程/补给、单项/撤销、批量与时间保留、筛选清空隐藏选择、历史/未来/无效输入只读、存储失败、复制实际小票、既定色板与错误 Web 入口撤下。另保留绘图、13 组业务和 16 组 AI/换照回归。

微信官方本地 `wcc` 15 个 WXML、`wcsc` 19 个 WXSS 编译通过。当前没有可用的微信自动化端口，未获得本次原生截图；编译和 wx 桩不等同真机视觉/读屏验收。没有上传、发布或生成新体验二维码。
